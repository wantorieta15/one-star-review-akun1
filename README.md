A deadpan one-star review of something essential, in a single line.

## Entry

> One star. Toothpaste surrenders the first ninety percent freely, then defends the last ten like it has something to hide.

## How it works

`main.py` (pure Python standard library, no network, no dependencies)
writes exactly that one line to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).

Run it:

```sh
python3 main.py
```
